### 🔢 Program 1: Basic Data Types

A foundational C++ program demonstrating the declaration, initialization, and output of standard data types.

#### 🚀 Key Features
* **Variable Initialization:** Stores a student roll number (`int`), grade (`char`), and fee amount (`float`)[cite: 1].
* **Standard I/O:** Utilizes the `<iostream>` library and `cout` to display the stored values cleanly to the console[cite: 1].
