### 📘 C++ Unit 1: Fundamentals & OOP Concepts

A comprehensive collection of fundamental C++ programs from the Unit 1 Code Book, designed to demonstrate core programming concepts ranging from basic data types to object-oriented programming (OOP) principles.

#### 🚀 Included Programs

*   **Program 1: Basic Data Types**
    *   **Scenario:** Store student roll number, grade, and fee amount[cite: 1].
    *   **Key Concepts:** Uses `iostream` for input/output, `int` for whole numbers, `char` for single characters, and `float` for decimal numbers[cite: 1].
*   **Program 2: if-else**
    *   **Scenario:** Check whether a student has passed or failed[cite: 1].
    *   **Key Concepts:** Demonstrates selection branching where `if` checks the pass condition and `else` executes when the condition is false[cite: 2].
*   **Program 3: Loop and Array**
    *   **Scenario:** Print marks of five students[cite: 2].
    *   **Key Concepts:** Uses an array to store five values and a `for` loop to repeat five times, accessing elements using an index variable `i`[cite: 2].
*   **Program 4: Functions**
    *   **Scenario:** Create an addition function for reuse[cite: 3].
    *   **Key Concepts:** Demonstrates how a prototype informs the compiler, how the function is called, and how values are received and returned[cite: 3, 4].
*   **Program 5: Class and Object**
    *   **Scenario:** Store student details using class and object[cite: 4].
    *   **Key Concepts:** Defines a blueprint using `class`, establishes data members (`string`, `int`) and member functions, and assigns object values via the dot operator[cite: 4].
*   **Program 6: Constructor and Destructor**
    *   **Scenario:** Show automatic object initialization and cleanup[cite: 4].
    *   **Key Concepts:** The constructor runs automatically upon object creation, while the destructor runs when the object ends to facilitate cleanup[cite: 5].
*   **Program 7: Static Member**
    *   **Scenario:** Count how many objects are created[cite: 5].
    *   **Key Concepts:** Uses a `static` member to define shared data belonging to the class, incrementing the count via the constructor for every new object[cite: 6].
*   **Program 8: Inline and Friend Function**
    *   **Scenario:** Access private data using inline getter and friend function[cite: 6].
    *   **Key Concepts:** Shows how an inline getter quickly returns values, and how a friend function allows external access to private class data[cite: 7].
