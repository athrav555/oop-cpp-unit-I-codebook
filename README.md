### 📊 Program 7: Static Members

A C++ OOP program illustrating how to share data across all instances of a class using static members.

#### 🚀 Key Features
* **Shared Class Data:** Uses a `static int count` variable that belongs to the class itself rather than any individual object[cite: 5, 6].
* **Instance Tracking:** Increments the shared static counter inside the constructor every time a new `Student` object is instantiated, effectively tracking the total number of objects[cite: 6].
